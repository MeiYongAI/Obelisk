These are exact navigation and stamina DOM extracts from the supplied
`The HentaiVerse（非ALT）.html` and `The HentaiVerse（ISK）.html` files.
Only `child_Character`, `child_Bazaar`, `child_Battle`, `stamina_readout`, and
`stamina_restore` are retained. Account fields, tokens, and unrelated scripts
are excluded. The Persistent recovery form contains only `recover=stamina`;
the Isekai recovery container is empty.

Tests that add a `synthetic_field` exercise form encoding only; that field is
not evidence of an actual server parameter. No test sends requests to HV.
